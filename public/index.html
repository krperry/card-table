        Keyboard Commands

        Press Escape to close this dialog and return focus to the game board.

        • Left Arrow: select previous card
        • Right Arrow: select next card
        • Home: select first card
        • End: select last card
        • Enter or Space: play selected card
        • D: draw a card
        • P: announce top discard card
        • T: announce whose turn it is and the top discard
        • N: announce direction and who plays next
        • C: announce how many cards are in your hand
        • H: announce your full hand
        • Q: read all playable cards and select the highest playable card
        • Shift+Q: read all playable cards and select the lowest playable card
        • S: announce your score
        • Shift+S: announce every player's score, highest to lowest
        • R / Shift+R: select highest / lowest red card
        • Y / Shift+Y: select highest / lowest yellow card
        • B / Shift+B: select highest / lowest blue card
        • G / Shift+G: select highest / lowest green card
        • Playing a Give Plus One works like a normal play; your turn continues so you can select any card from your hand and press Enter to pass it to the next player
        • ?: open this help
        • Escape: close this help
