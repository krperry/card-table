Tables

Waiting for tables...

    Set a 4-digit code so only players who know it can join. Leave it blank to keep the table open to anyone.

    Hearts always seats exactly four players. If fewer than four have joined, starting the table fills the rest with computer players.

    Spades always seats exactly four players in fixed partnerships: seats 1 & 3 are partners, seats 2 & 4 are partners. If fewer than four have joined, starting the table fills the rest with computer players.

    Cribbage is always a two-player game. If only one player has joined, starting the table fills the second seat with a computer player.
